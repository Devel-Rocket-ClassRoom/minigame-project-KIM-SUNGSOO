# UI Prefabs

- `UI_HUD.prefab` : HUD 컴포넌트 + 골드/라이프/웨이브 TMP 텍스트 + Start Wave 버튼
- `UI_BuildMenu.prefab` : TowerBuildMenu (빈 슬롯 클릭 시 표시)
- `UI_UpgradeMenu.prefab` : TowerUpgradeMenu (건설된 타워 클릭 시 표시)
- `UI_BuildButton.prefab` : BuildMenu에서 동적 생성되는 버튼
- `UI_BranchButton.prefab` : UpgradeMenu에서 동적 생성되는 분기 버튼
